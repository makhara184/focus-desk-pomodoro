# FocusDesk — Ambient Pomodoro Workspace

![JavaScript](https://img.shields.io/badge/Vanilla%20JS-F7DF1E?style=flat-square&logo=javascript&logoColor=black)
![Zero Dependencies](https://img.shields.io/badge/Dependencies-Zero-22c55e?style=flat-square)

A minimalist, zero-dependency Pomodoro deep-work workspace featuring synthesized brown-noise ambient audio (via Web Audio API), a persistent task queue, and keyboard shortcuts.

## Features
- **Focus / Short Break / Long Break** presets with live tab-title countdown.
- **Built-in Web Audio Synthesizer**: Generates soothing brown noise and completion chimes completely offline with no audio files needed.
- **Persistent Task Queue & Daily Counter**: Saved automatically in `localStorage`.
- **Keyboard Shortcuts**: `Space` to start/pause, `R` to reset.

## Quick Start
Open `index.html` in any modern web browser. No build step required.
